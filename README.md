## Run it

```sh
python3 draw_image.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies `entry.png` (1024x1024, drawn by `draw_image.py`) to `/output/entry.png`, using only the Python standard library, with no network, so two runs write the same bytes.
